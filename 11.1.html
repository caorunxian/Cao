Web 前端的长度单位

曹润贤 · 高级网页设计课堂实践 11.1 · 拖动浏览器窗口大小可观察相对单位的变化

一、绝对单位

px（像素）200px

网页中最常用的长度单位，不随屏幕大小变化。

width: 200px

cm / mm / in / pt / pc

物理长度单位。屏幕上默认 1in = 96px，1in = 72pt = 6pc，1cm ≈ 37.8px，主要用于打印样式。

1cm
10mm
1in
72pt
12pc

二、相对字体单位

em

相对父元素的 font-size。子元素里嵌套 em 会成倍放大（20px × 2 = 40px）。

父元素 font-size: 20px
子元素 2em = 40px

rem

相对根元素 html 的 font-size（默认 16px），不受父元素影响，适合做整体缩放。

父元素 font-size: 32px
子元素 2rem = 32px

ex / ch

ex 相对字符 "x" 的高度，ch 相对字符 "0" 的宽度（各 10 个单位）。

width: 10ex
width: 10ch

三、相对视口与父容器单位

%（百分比）

相对父容器的尺寸，常用于流式布局。下例为父容器宽度的 60%。

width: 60%

vw / vh

相对浏览器视口：1vw = 视口宽度的 1%，1vh = 视口高度的 1%。调整窗口大小试试！

height: 8vh（视口高度的 8%）
width: 25vw

vmin / vmax

vmin 取视口宽高中较小值的百分比，vmax 取较大值的百分比。

15vmin

四、单位速查表

单位 类型 参照 常见用途
px 绝对 设备像素 边框、阴影等固定尺寸
cm / mm / in / pt / pc 绝对 物理长度（1in = 96px） 打印样式
em 相对 父元素 font-size 段落内局部缩放
rem 相对 根元素 html 的 font-size 整体布局与响应式缩放
% 相对 父容器宽高 流式布局
vw / vh 相对 视口宽度 / 高度的 1% 整屏布局、滚动区域
vmin / vmax 相对 视口宽高较小 / 较大值 横竖屏自适应
ex / ch 相对 字符 x 高度 / 字符 0 宽度 与文字排版对齐
