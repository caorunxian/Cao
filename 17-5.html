⏰ JavaScript 定时器

setTimeout（一次性延迟）· setInterval（周期性循环）· 生活场景演示

一次性

setTimeout

setTimeout(callback, delay)
等 delay 毫秒之后，执行一次 callback。
相当于"闹钟"：响完就停。
// 3 秒后弹一次框 var crx_t = setTimeout(function() { alert('时间到！'); }, 3000); // 还没响就取消 clearTimeout(crx_t);
🎯 演示：倒计时炸弹（5 秒后爆炸 💥）
点击开始
周期性

setInterval

setInterval(callback, interval)
每隔 interval 毫秒，重复执行 callback，直到手动停止。
相当于"节拍器"：一直滴答。
// 每秒数一次数 var crx_i = 0; var crx_clock = setInterval(function() { crx_i++; console.log(crx_i); if (crx_i >= 10) { clearInterval(crx_clock); } }, 1000);
⏱ 演示：秒表（每秒 +1）

📌 一句话区别：
setTimeout 是"等一会做一件事"，setInterval 是"每隔一会一直做"。
两者都会返回一个定时器 ID，用 clearTimeout(id) / clearInterval(id) 可以提前取消。
⚠ 注意：定时器不是精确计时（主线程被阻塞时会延后执行），适合做"演示 / 动画 / 延迟 / 轮询"，不适合做精准时间戳。
