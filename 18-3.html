基于知识库的智能客服系统架构图

SVG 矢量绘制 · 六层架构 · 检索增强生成（RAG）技术路线 · 面向科研的评测与迭代闭环

用户交互层 接入与会话层 对话理解层 知识库与检索层 大模型生成层 支撑与评测层 主数据流 评测反馈回路

架构说明（科研方向）

1. 在线链路（RAG 三阶段）
  • 检索（Retrieval）：用户提问经 NLU 解析后改写为检索查询，走 混合检索（BM25 稀疏 + Dense 稠密向量），召回 Top-k 文档片段；
  • 增强（Augmentation）：经 Rerank 交叉编码器重排后筛选高相关片段，与对话历史一同组装进 Prompt 上下文；
  • 生成（Generation）：LLM 基于证据片段生成答案，输出侧做 事实一致性校验与引用溯源，抑制幻觉。
2. 离线知识构建
  • 文档解析（PDF / Word / HTML）→ 文本清洗去噪 → 语义分块（按语义边界 + 滑动窗口）→ Embedding 向量化 → 写入向量库并建立元数据索引；
  • 支持增量索引与知识版本管理，保障答案可追溯、可审计。
3. 可研究的评测方向
  • 检索侧：Recall@k、MRR、nDCG，分块策略与检索器组合的消融实验；
  • 生成侧：EM、F1、BLEU、忠实度（Faithfulness）与人工偏好评分；
  • 闭环迭代：线上日志 → 数据标注 → 微调 / SFT / RLHF → A/B 实验验证，形成 数据—模型—评测 的科研闭环。
