JSON.parse(text) —— 把 JSON 字符串解析成 JS 对象 / 数组
JSON.stringify(value, replacer?, space?) —— 把 JS 对象 / 数组序列化成 JSON 字符串
第二参数 replacer 可做过滤，第三参数 space 控制缩进空格数（常用 2 或 4）
