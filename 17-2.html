📝 关键代码： 
fetch(apiUrl)
  .then(function(res) { return res.json(); })
  .then(function(data) {
      // data 就是接口返回的 JS 对象
      render(data);
  })
  .catch(function(err) {
      console.error('请求失败:', err);
  });
本页使用的接口 https://api.open-meteo.com 支持跨域（CORS），无需任何密钥即可访问。 公开 CORS 接口可在浏览器里直接 fetch，不会被同源策略拦截。
